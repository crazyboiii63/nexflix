NEXFLIX Personal Cinema — Android-ready PWA source

WHAT'S INCLUDED
- Netflix-inspired personal library UI
- Browse/search/filter catalogue
- My List and Continue Watching
- Add your own video files (stored in browser IndexedDB)
- Add poster images and descriptions
- Sample public demo videos for testing
- Installable PWA manifest and service worker

ANDROID INSTALL
1. Upload the contents of this folder to an HTTPS static host (for example GitHub Pages).
2. Open the hosted site in Chrome on Android.
3. Open Chrome menu (⋮) and choose "Install app" or "Add to Home screen".
4. Launch NEXFLIX from your home screen.

IMPORTANT
This bundle is a web app/PWA, not a signed APK. It can be installed on Android through Chrome after HTTPS hosting.
The catalogue includes sample entries/placeholders, not commercial movie or anime episodes. Add only videos you own or have permission to stream.
Uploaded video files are stored locally in this browser on this device. Clearing browser site data can erase them.
